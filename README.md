HydraML : Prédire la conformité et segmenter la performance des stations d'épuration françaises avec PySpark
==============================

Pipeline Big Data appliqué à 298 000 mesures réglementaires d'autosurveillance (Agence Seine-Normandie, décembre 2022) pour répondre à deux problématiques de l'assainissement : (1) prédire la conformité réglementaire d'un rejet d'eaux usées traitées (classification binaire, 3 algorithmes comparés), (2) segmenter le parc des 1 533 STEU en profils de performance homogènes (clustering avec PCA et silhouette score).

    │
    ├── models             <- Trained and serialized models, model predictions, or model summaries

    │                         `1.0-jqp-initial-data-exploration`.
    │
    ├── references         <- Data dictionaries, manuals, and all other explanatory materials.
    │
    ├── reports            <- Generated analysis as HTML, PDF, LaTeX, etc.
    │   └── figures        <- Generated graphics and figures to be used in reporting
    │

    │

    │   │
    │   ├── data           <- Scripts to download or generate data

    │   │
    │   ├── features       <- Scripts to turn raw data into features for modeling
    │   │   └── build_features.py
    │   │
    │   ├── models         <- Scripts to train models and then use trained models to make
    │   │   │                 predictions
    │   │   ├── predict_model.py
    │   │   └── train_model.py
    │   │
    │   └── visualization  <- Scripts to create exploratory and results oriented visualizations
    │       └── visualize.py
    │
